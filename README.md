Authentication — how to obtain and use a JWT.

cURL examples — event listing, event creation as admin, and successful or unsuccessful reservation attempts.

API documentation — Swagger UI and OpenAPI schema URLs.

Testing and coverage — test commands and coverage evidence.

CI pipeline — what runs and when a build fails.

Database indexes — which indexes exist and why they help particular queries.

Known limitations and future improvements.
